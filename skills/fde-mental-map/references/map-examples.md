# 五张示例技术地图

示例不是对任何真实公司部署的断言。展示了不同关系，切勿硬拼为单线。

## 1. 浏览器访问一个 AI Web 应用（请求与数据流）

~~~text
用户浏览器
  | (DNS 查询：得到入口 IP)
  | (HTTPS 请求)
  v
公网入口/负载均衡/防火墙
  | (流量转发)
  v
Nginx / API Gateway
  | (HTTP 反向代理)
  v
AI 应用后端
  |----------> 数据库 (读写用户、会话、业务记录)
  |----------> OSS (保存/读取上传附件)
  |----------> Model API (调用模型推理)
  |
  v
应用产生响应 --> 代理 --> 用户浏览器
~~~

注意：DNS 并不是每次业务 HTTP 请求都会“流过”的反向代理；数据库、OSS 与 Model API 也不必串成一条直线。

## 2. 服务究竟运行在哪里（包含/部署关系）

~~~text
物理服务器 / 云资源
├── VM / 云主机 A
│   └── Linux
│       └── Docker Engine
│           ├── Container: Nginx
│           └── Container: Backend
│               └── 挂载持久化 Volume
└── VM / 云主机 B
    └── Linux
        └── Database 服务
~~~

注意：容器一般是隔离的进程运行实例，典型 Linux 容器共享宿主内核；数据库也可能是独立的云托管服务。

## 3. 从写代码到线上生效（交付流程）

~~~text
代码修改 -> commit -> push -> PR -> merge
                                      |
                                      v
                              Workflow 触发条件？
                                  | 是     | 否
                                  v        v
                                 CI      无 Run
                                  |
                            构建/测试/发布
                                  |
                                 CD
                                  |
                            部署目标环境
                                  |
                          实际运行版本/健康检查
                                  |
                              用户看到更新
~~~

FDE 追问：目标分支、path filter、Actions Run、构建产物 SHA、生产部署 SHA、服务运行版本、缓存或流量切换。

## 4. 客户内网 Windows Agent（控制流与任务流）

~~~text
云端控制面 / Gateway
           ^
           | (Agent 主动发心跳、轮询任务)
           |
客户内网 Windows Agent
           |
           v
        Worker
           |
           v
 Playwright / 本地工具
           |
           v
 内网浏览器访问内部业务系统
           |
           v
 执行结果/日志安全地回传云端
~~~

为什么云端不直接连接？客户内网通常没有供云端任意直连的入站入口。Agent 可通过受控的出站连接领取任务，但仍需认证、授权、超时、重试、审计。

## 5. AI 知识库问答（业务处理流程）

~~~text
用户提问 -> 应用 API
             ├── 认证与会话
             ├── 检索相关资料（RAG，可选）
             ├── Model API 生成回答
             ├── 数据库存对话记录
             └── OSS 保存附件
               |
               v
           返回用户
~~~

学习提问：哪些业务真的需要检索？何时长 Context 足够？错误可能出在索引、检索、权限过滤、模型调用、生成还是前端展示？
